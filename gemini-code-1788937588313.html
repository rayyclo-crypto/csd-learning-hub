資料 B 倡議報導

取材自2020年7月的樂施會倡議：
在推行公平貿易前，斯里蘭卡的農民支援組織 SOFA 的小農所種的香料和茶葉都是由中間人收購。中間人在收購時多番壓價，令他們無法得到一個合理的回報。他們於是組成小農合作社，以公平貿易原則運作。協會設有公平貿易社區發展基金，為農民會員免費提供多種香料種子、茶樹的幼苗，牛羊等牲畜等，以推動有機耕作；又支持當地婦女參與自僱計劃，製作採茶用的背籃，自力更生；並向小農戶的孩子提供學前教育，讓整個社區一同受惠。

資料 C 新聞稿

取材自2020年6月英國公平貿易基金會的新聞稿：
雀巢公司宣布旗下品牌 KitKat 不再採購使用公平貿易可可和公平貿易蔗糖，此舉意味着南半球數千名可可種植者和糖農每年損失近 200 萬英鎊的公平貿易基金。西非的可可農民每天只能賺取不到一英鎊，遠低於極度貧困線，這個數字僅略高於一塊 KitKat 朱古力的價格。

回顧過去 10 年 KitKat 在英國及愛爾蘭推出使用公平貿易可可的產品，為農民的生活帶來了極大的改變。可可合作社受益於公平貿易最低價格和固定保證金的安全網，能夠建造教室、培訓當地婦女創業並使收入多元化。國際公平貿易組織的研究也顯示，2019年非洲科特迪瓦公平貿易可可合作社及其農民成員因為公平貿易整體經濟價值增長了近35%。

題號 1(a)

資料數據理解題

滿分：1 分
題目：根據資料A，以下哪些是正確的描述？
(1) 可可種植者在朱古力供應鏈中獲取的利潤較低。
(2) 有機及公平貿易認證標籤可增加產品價值。
(3) 運輸業在朱古力供應鏈中佔主導地位。
正確答案：B (只有 (1) 和 (2))
  • ✓ (1) 正確：資料 A 顯示可可種植者分得利潤僅 7.7% 或 11.8%，為鏈內最少或次少部分，屬「較低」。
  • ✓ (2) 正確：加入認證後，可可種植者（7.7%→11.8%）及磨粉加工（7.6%→11.6%）所得價值比例提升，增加了整體產品價值。
  • ✗ (3) 錯誤：資料 A 將「零售商及運輸業」合併計算（49.5%及43.5%），無法單獨推論運輸業佔「主導地位」。
🔍 核心概念 / 數據解讀技巧 DSE 數據選擇題常設「合併項目陷阱」。當圖表將「零售商與運輸業」合併呈現時，不能直接將整個百分比歸功於單一行業（如運輸業），需保持邏輯嚴謹。

題號 1(b)

因素分析題

滿分：2 分
題目：根據資料 B，指出及說明一個導致農民難以獲取合理回報的因素。（2分）
標準答題範文（三色筆結構）：

導致農民難以獲取合理回報的因素是缺乏議價能力。 資料B顯示在推行公平貿易前，中間人在收購時多番壓價，令斯里蘭卡的農民無法得到一個合理的回報。 農民通常處於供應鏈較低和被動的地位，較少渠道得知市場訊息，故缺乏對市場價格的理解和談判實力，難以為自己種植的農產品爭取到合理的收購價錢，故農民面對中間人多番壓價時顯得力不從心，只能接受中間人給出的低價條件以盡快出售農產品。

🔍 核心評分標準 (2分)
  • 1分：準確指出核心因素（如：缺乏議價能力 / 資訊不對稱 / 依賴中間人）。
  • 1分：能結合資料內容進行邏輯推論，解釋「為何」該因素導致獲利被壓低。
🚀 延伸預測 考官常考「歸因題」。未來可試著將「議價能力不足」套用至其他發展中國家勞工或弱勢生產者，並溫習「小農合作社」如何透過集體談判權來扭轉此困境。
題號 1(c)

影響分析題 (正負雙向)

滿分：4 分
題目：根據資料 A 及 C，說明跨國企業在全球貿易中可能造成的一個正面影響和一個負面影響。（4分）
標準答題範文（分段三色筆）：
正面影響 (2分)

跨國企業在全球貿易中可能造成的一個正面影響是推動發展中國家發展。 根據資料 C，2019 年非洲科特迪瓦整體經濟價值增長了近 35%。 跨國企業進行國際分工，將生產活動分配至世界各地。而每一環的分工都創造了產品的價值，帶動不同行業的發展。同時，跨國企業透過全球分銷網絡，帶動貨物進出口貿易，為發展中國家創造財富。

負面影響 (2分)

跨國企業在全球貿易中可能造成的一個負面影響是加劇財富分配不平均。 資料 A 顯示可可種植者在沒有公平貿易標籤的朱古力價值分配中佔比偏低，只有 7.7%。而資料 C 西非的可可農民每天只能賺取不到一英鎊。 當跨國企業不按公平貿易原則採購，給予生產者不合理的薪酬待遇，會令發展中國家的農民受剝削，從而加劇財富分配不平均。

得分維度 表現說明
正面影響 (2分) 清晰指出正面影響（如：帶動經濟發展/創造財富），並精準引述資料 C 科特迪瓦數據，推論合理。
負面影響 (2分) 清晰指出負面影響（如：貧富懸殊/剝削農民），並同時結合資料 A (7.7%) 與 資料 C (不足1英鎊) 進行論述。
🔍 核心概念：跨國企業的雙刃劍效應 跨國企業是「經濟全球化」的主要推手。正面能帶來資本、技術與國際市場；負面則可能引發「競相廉價賣勞力 (Race to the bottom)」與利益壟斷問題。
🚀 延伸預測 DSE 經常要求學生評估「跨國企業的社會責任 (CSR)」。溫習時可留意企業終止公平貿易合作（如雀巢案例）對當地可持續發展帶來的衝擊。
題號 1(d)

資料支持度論述題

滿分：6 分
題目：「推動公平貿易能有效協助農民發展生計，提升生活水平。」所提供的資料如何支持這個看法？解釋你的答案。（6分）
標準答題範文（三步曲結構）：
論點一：保障農民收入與經濟安全

首先，資料反映推動公平貿易能保障農民收入，令農民能直接獲得農產品銷售所得的收入。 資料 B 顯示以公平貿易原則運作的小農合作社，可避免中間人在收購時壓價，保障農民獲得合理回報。 推動公平貿易確保農民得到一定且穩定的回報，令農民的收入受到保障，同時避免遭受中間人壓價的機會，減低農民在貿易中被剝削的風險，令農民能為農產品爭取到更合理的價錢，提升收入比例，有助提高收入水平以改善生活。

論點二：改善生產模式與技術支援

其次，資料反映推動公平貿易能改善生產模式，提升農民生產能力，有助提高農民的農產品質量和生產效率。 資料 B 顯示公平貿易社區發展基金，為農民會員免費提供多種香料種子、茶樹的幼苗，牛羊等牲畜等，以推動有機耕作。 公平貿易機制為農民提供技術和資源上的支持。農民從中學習可持續農業方法和市場知識，瞭解有機農產品的經濟回報更高，同時獲得農業所需的資源，減少耕作成本。此有助促使農民發展有機耕作，採用經濟回報更高的耕作模式，有助提高農民的農產品質量和生產效率，長遠改善生活。

論點三：推動教育發展與社區升級

最後，資料反映推動公平貿易能推動教育發展，有助提高農民的知識和生活水平。 資料 B 顯示公平貿易社區發展基金向小農戶的孩子提供學前教育，讓整個社區一同受惠；資料 C 亦顯示受益於公平貿易的可可合作社能夠建造教室，發展教育。 推動公平貿易能改善當地教育設施和資源，彌補當地教育資源匱乏的問題，從而改善農民子女的學習條件，提升整體社區教育質素，向他們提供接受公平教育的機會。此有助提升其知識水平和競爭力，給予農民下一代改善生活和投資未來的機會。

DSE 評卷維度 (高分表現)
  • 5-6 分：能全面及適當運用資料 A, B, C 的多個要點，從「個人收入、生產技術、社區教育」多角度深入論證，邏輯嚴謹。
  • 3-4 分：能運用部分資料進行說明，但論證較為平鋪直敘，角度較為單一。
  • 1-2 分：僅抄錄資料，未能有效對應「協助發展生計」及「提升生活水平」。
🚀 延伸預測與答題框架 回答長題時，切忌單純寫「農民變有錢」。必須運用「三步曲（主題句 → 引用資料 → 邏輯推論）」，並將「生活水平」拆解為：經濟層面（收入保障）、生產層面（技能升級）、社會層面（教育與婦女權益），這樣才能獲得最高等級 (5-6分)。
